# astrbot_plugin_cost_stats（每日耗费统计）

为肆小喵提供的每日花费统计插件，结合 DeepSeek 官方高峰/空闲两档定价与本地 `provider_stats` 数据，支持零 token 消耗的命令查账、定时日报与官方 CSV/ZIP 账单对账。

## 命令

| 命令 | 说明 |
|---|---|
| `/耗费` | 查看近 7 天（可配置）每日花费、高峰/空闲拆分、调用次数与缓存命中率 |
| `/耗费 14` | 查看近 14 天每日花费（1~90 天） |
| `/耗费 今天` / `/今日耗费` | 查看今日花费 |
| `/耗费 昨天` | 查看昨日花费 |
| `/耗费 2026-11-20` | 查看指定日期花费 |
| `/账单核对` | 读取 `plugin_data/astrbot_plugin_cost_stats/bills/` 下最新的官方 CSV/ZIP，汇总并与本地 `provider_stats` 对账 |

## 计费口径（DeepSeek 官方两档价）

- **高峰时段**（北京时间工作日 09:00–12:00、14:00–18:00）：缓存命中 `¥0.04/M`、未命中 `¥2.0/M`、输出 `¥8.0/M`
- **空闲时段**（其余时段及周六周日全天）：缓存命中 `¥0.02/M`、未命中 `¥1.0/M`、输出 `¥4.0/M`

所有单价均可在插件配置中调整。
